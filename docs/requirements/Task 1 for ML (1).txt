Missing Values — Find missing values and choose a justified handling method (e.g., imputation or removal).  
Duplicate Rows — Detect duplicate records; remove genuine duplicates when appropriate.  
Outlier Detection — Use appropriate plots or statistical techniques to identify potential outliers.  
Outlier Treatment Techniques — Compare possible actions such as keeping, capping, transforming, or 
removing values; justify your choice.

03  Exploratory Data Analysis (EDA) 
Investigate patterns, relationships, and distributions using tables and appropriate visualizations. 
1.  Univariate Analysis 
Analyze each feature individually (distribution, central tendency, spread, and unusual patterns).  
2.  Feature vs. Target Analysis 
Compare each important feature with the target to identify meaningful associations.  
3.  Feature-to-Feature Analysis 
Explore relationships between predictors and note possible overlap or interactions.  
4.  Correlation Analysis 
Calculate and visualize correlations where suitable; interpret direction and strength.  
5.  GroupBy / Statistical Summary Analysis 
Group by relevant categories and compare counts, averages, medians, or other statistics.
